Módulo 01

Sumas de Riemann

Una suma de Riemann aproxima el área bajo una curva dividiéndola en rectángulos. Mientras más rectángulos usas, mejor es la aproximación, y en el límite obtienes la integral definida.

Teoría Visualizador interactivo Ejemplos resueltos

¿Qué es una suma de Riemann?

Para estimar el área bajo la gráfica de una función \(f\) entre \(x=a\) y \(x=b\), dividimos el intervalo \([a,b]\) en \(n\) subintervalos del mismo ancho y, sobre cada uno, levantamos un rectángulo. La suma de las áreas de esos rectángulos es una suma de Riemann.

\[ \Delta x = \frac{b-a}{n}, \qquad x_i = a + i\,\Delta x \quad (i = 0, 1, \dots, n) \]

Cada rectángulo tiene base \(\Delta x\) y altura igual al valor de \(f\) en un punto de su subintervalo. Según qué punto elijas, obtienes tres variantes:

Suma izquierda

\[ L_n = \sum_{i=0}^{n-1} f(x_i)\,\Delta x \]

La altura de cada rectángulo es el valor de \(f\) en el extremo izquierdo del subintervalo.

Suma derecha

\[ R_n = \sum_{i=1}^{n} f(x_i)\,\Delta x \]

La altura es el valor de \(f\) en el extremo derecho del subintervalo.

Punto medio

\[ M_n = \sum_{i=1}^{n} f(\bar{x}_i)\,\Delta x \] \[ \bar{x}_i = \frac{x_{i-1}+x_i}{2} \]

La altura es el valor de \(f\) en el centro del subintervalo.

¿Sobreestima o subestima?

Si \(f\) es creciente en \([a,b]\), la suma izquierda subestima el área y la derecha la sobreestima. Si \(f\) es decreciente, ocurre lo contrario. El punto medio suele compensar los errores de ambos lados, por eso normalmente es más preciso con el mismo \(n\).

De la suma a la integral

Cuando \(n\) crece, \(\Delta x\) se hace cada vez más pequeño y las tres sumas se acercan al mismo valor: la integral definida.

\[ \int_a^b f(x)\,dx = \lim_{n\to\infty} \sum_{i=1}^{n} f(x_i^*)\,\Delta x \]

Aquí \(x_i^*\) es el punto elegido en cada subintervalo (izquierdo, derecho o medio). Para una función continua, el límite es el mismo sin importar cuál elijas.

Ejemplos resueltos paso a paso

Ejemplo 1: función creciente

Calcule \(L_4\), \(R_4\) y \(M_4\) para \(f(x)=x^2\) en \([0,2]\) y compare con el valor exacto.

Paso 1. Ancho de cada subintervalo

\[ \Delta x = \frac{b-a}{n} = \frac{2-0}{4} = 0.5 \]

Paso 2. Puntos y valores de la función

Los extremos son \(x_i = 0.5\,i\). Los puntos medios están en el centro de cada subintervalo.

\(i\)01234
\(x_i\)00.511.52
\(f(x_i)\)00.2512.254
Subintervalo1234
\(\bar{x}_i\)0.250.751.251.75
\(f(\bar{x}_i)\)0.06250.56251.56253.0625

Paso 3. Suma izquierda (usa \(x_0, x_1, x_2, x_3\))

\[ L_4 = 0.5\,[\,0 + 0.25 + 1 + 2.25\,] = 0.5 \cdot 3.5 = 1.75 \]

Paso 4. Suma derecha (usa \(x_1, x_2, x_3, x_4\))

\[ R_4 = 0.5\,[\,0.25 + 1 + 2.25 + 4\,] = 0.5 \cdot 7.5 = 3.75 \]

Paso 5. Suma de punto medio

\[ M_4 = 0.5\,[\,0.0625 + 0.5625 + 1.5625 + 3.0625\,] = 0.5 \cdot 5.25 = 2.625 \]

Paso 6. Valor exacto

\[ \int_0^2 x^2\,dx = \left[\frac{x^3}{3}\right]_0^2 = \frac{8}{3} \approx 2.6667 \]

Conclusión

Como \(f(x)=x^2\) es creciente en \([0,2]\), se cumple \(L_4 < \tfrac{8}{3} < R_4\). Los errores son: izquierda \(\approx 0.9167\), derecha \(\approx 1.0833\) y punto medio \(\approx 0.0417\). El punto medio es la mejor aproximación con diferencia.

Ejemplo 2: función decreciente

Aproxime \(\displaystyle\int_1^3 \frac{1}{x}\,dx\) usando \(L_5\), \(R_5\) y \(M_5\).

Paso 1. Ancho de cada subintervalo

\[ \Delta x = \frac{3-1}{5} = 0.4 \]

Paso 2. Puntos y valores de la función

\(i\)012345
\(x_i\)11.41.82.22.63
\(f(x_i)\)10.714290.555560.454550.384620.33333
Subintervalo12345
\(\bar{x}_i\)1.21.62.02.42.8
\(f(\bar{x}_i)\)0.833330.6250.50.416670.35714

Paso 3. Suma izquierda

\[ L_5 = 0.4\,[\,1 + 0.71429 + 0.55556 + 0.45455 + 0.38462\,] = 0.4 \cdot 3.10902 \approx 1.2436 \]

Paso 4. Suma derecha

\[ R_5 = 0.4\,[\,0.71429 + 0.55556 + 0.45455 + 0.38462 + 0.33333\,] = 0.4 \cdot 2.44235 \approx 0.9769 \]

Paso 5. Suma de punto medio

\[ M_5 = 0.4\,[\,0.83333 + 0.625 + 0.5 + 0.41667 + 0.35714\,] = 0.4 \cdot 2.73214 \approx 1.0929 \]

Paso 6. Valor exacto

\[ \int_1^3 \frac{1}{x}\,dx = \Big[\ln|x|\Big]_1^3 = \ln 3 - \ln 1 = \ln 3 \approx 1.0986 \]

Conclusión

Ahora \(f(x)=1/x\) es decreciente, así que el orden se invierte respecto al ejemplo anterior: \(R_5 < \ln 3 < L_5\). Los errores son: izquierda \(\approx 0.1450\), derecha \(\approx 0.1217\) y punto medio \(\approx 0.0058\). De nuevo, el punto medio gana. Puedes comprobarlo en el visualizador eligiendo \(1/x\), el intervalo \([1,3]\) y \(n=5\).
